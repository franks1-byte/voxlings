# Voxlings

A 3D voxel monster-catching adventure that runs in the browser.

- **Region 1 — Pixel Island:** 5 worlds, 7 gyms, 80 Voxlings.
- **Region 2 — Haraya:** 5 new worlds, 5 gyms + a Champion, 34 new Voxlings, 5 legendaries and 60 new skills. You start from zero, and it is harder (medium to hard).
- Each region keeps its own progress. Travel between them with Captain Alon's Sky Ferry.
- Optional online account keeps your save safe across devices.

## Play

Open the website and press **NEW GAME**. On Chrome/Edge you can press **⬇ INSTALL VOXLINGS APP** at the top to install it like a normal app (works offline too).

## Controls

| Action | Keys |
| --- | --- |
| Move | Arrow keys / WASD |
| Talk / interact | E or Enter |
| Run | Hold Shift or B |
| Fish (face water) | F |
| Menu | Esc |
| Speed x2 | X |

On phones, use the on-screen D-pad and **A** button.

## Files

- `index.html` — the whole game (Three.js and the font are built in)
- `manifest.webmanifest`, `sw.js`, `icon-*.png` — installable app + offline support
